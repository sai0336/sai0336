## Featured projects

### 🏠 [ESP32-S3 Smart Home Automation](https://github.com/sai0336/esp32-s3-home-automation)

An eight-channel home-automation controller I built and installed for everyday use. It combines **ESP RainMaker**, **Google Home**, an **IR remote**, and **physical push buttons** to control appliances. I report that the installed system has been operating for several months.

**Tech:** ESP32-S3, Arduino C++, ESP RainMaker, Wi-Fi, IR, relay control  
**Code and documentation:** [View repository](https://github.com/sai0336/esp32-s3-home-automation)

> The public sketch is a documented sharing version with a placeholder provisioning PIN. The home installation and mains wiring have not been independently safety-certified.
